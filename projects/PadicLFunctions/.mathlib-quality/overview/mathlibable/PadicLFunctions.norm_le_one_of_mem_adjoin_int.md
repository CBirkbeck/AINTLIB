### Statement (Phase 1)

`PadicLFunctions.norm_le_one_of_mem_adjoin_int` is a theorem stating the following:

> Let `L` be an ultrametric (nonarchimedean) normed field, and let `z ∈ L` with `‖z‖ ≤ 1`. Then every element `s` of the `ℤ`-subalgebra `ℤ[z]` generated by `z` satisfies `‖s‖ ≤ 1`.

In valuation-theoretic language: the closed unit ball `{x : ‖x‖ ≤ 1}` (the valuation ring / ring of integers `𝒪_L`) contains the subring `ℤ[z]` generated by any norm-≤-1 element. This is the elementary half of "the valuation ring is integrally closed and contains ℤ".

Variables / typeclasses involved (Lean side):
- `(p : ℕ) [Fact p.Prime]` — section variable; **not used** in this lemma (it is a residual section parameter).
- `{L : Type*} [NormedField L]` — the ambient nonarchimedean normed field.
- `[IsUltrametricDist L]` — the ultrametric/strong-triangle hypothesis (`‖x+y‖ ≤ max ‖x‖ ‖y‖`). This is the load-bearing hypothesis; without it the closed unit ball is not closed under addition.
- `[NormedAlgebra ℚ_[p] L]`, `[CompleteSpace L]` — `omit`ted for this lemma (the `omit` line at `ExtLog.lean:193`); genuinely unused.

Hypotheses (Lean side):
- `(hz1 : ‖z‖ ≤ 1)` — the generator lies in the closed unit ball.
- `(hs : s ∈ Algebra.adjoin ℤ ({z} : Set L))` — `s` is in the `ℤ`-subalgebra generated by `z`.

Conclusion (math): `‖s‖ ≤ 1`, i.e. `s` lies in the valuation ring.

Conclusion (Lean): `‖s‖ ≤ 1`.

Proof body (4 substantive cases of `Algebra.adjoin_induction`):
- `mem`: `s = z`, use `hz1`.
- `algebraMap r` (`r : ℤ`): `‖(r : L)‖ ≤ 1` via `IsUltrametricDist.norm_intCast_le_one`.
- `add`: `IsUltrametricDist.norm_add_le_max` then `max_le`.
- `mul`: `norm_mul` then `mul_le_one₀`.

### Literature summary (Phase 3)

Concept identified as: **the ring of integers / valuation ring of a nonarchimedean (ultrametric) field** = the closed unit ball `{x : ‖x‖ ≤ 1}`, which is a **subring**; and the elementary fact that it **contains every subring generated by norm-≤-1 elements** (a fortiori the integral closure of ℤ).

Sources agree on the standard form: **yes** — unanimous across MIT 18.785, Wikipedia, nLab, Cambridge/UChicago lecture notes, and Krull's theorem.

Most general standard form: For a (semi)normed ring `R` whose norm is **nonarchimedean** (`‖x+y‖ ≤ max ‖x‖ ‖y‖`), submultiplicative (`‖xy‖ ≤ ‖x‖‖y‖`), and satisfies `‖1‖ = 1`, the set `{x : ‖x‖ ≤ 1}` is a subring. Consequently any subring generated by elements of norm ≤ 1 lies inside it. Specialising the generating set to `{z}` over `ℤ` gives exactly the user's lemma.

Generality dimensions where the literature varies:
  - **Ambient structure**: from non-Archimedean field (the textbook case, what the user uses) → general ultrametric *ring* with `‖1‖ = 1` (`NormOneClass`). The field structure and completeness are NOT needed for this closure fact; only the ultrametric + submultiplicative + norm-one properties are.
  - **Generating set**: literature states the closure property for the whole ball at once; the lemma is the special "`ℤ`-adjoin of one element" instance.
  - **Coefficient ring**: ℤ here; the general statement is base-ring-free (the ball is a subring, period).

Disagreement with the literature: **none.** The user's form is a correct, strictly-special case of the standard valuation-ring closure fact.

    def IsUltrametricDist.unitClosedBallSubring (R : Type*) [SeminormedRing R] [NormOneClass R]

## Verdict: `PadicLFunctions.norm_le_one_of_mem_adjoin_int`

**Category:** **NO-composable-from-mathlib**

**Evidence:**
- Literature search (Phase 3): unanimous — `{x : ‖x‖ ≤ 1}` is the valuation ring/ring of integers, a subring, integrally closed, containing ℤ (MIT 18.785, Wikipedia, nLab, Krull). The statement is textbook-elementary; not a named result.

- Composition check (Phase 6): COMPOSABLE in 1 `adjoin_le` call against a bundled closed-unit-ball subring — and the project already has that subring (`integerRing`).

**Rationale (1–2 paragraphs):**

This lemma is a by-hand proof, via `Algebra.adjoin_induction`, of the lattice fact "`ℤ[z] ⊆ {x : ‖x‖ ≤ 1}`" — i.e. *the adjoin is contained in the valuation ring*. In mathlib's idiom that is `Algebra.adjoin_le` applied to the closed unit ball **as a bundled `Subring`**. The mathematics (Phase 3) confirms `{‖·‖ ≤ 1}` is a subring in any ultrametric `NormOneClass` ring and is the standard ring of integers; the four `adjoin_induction` cases the author writes (`mem`/`algebraMap`/`add`/`mul`) are exactly that subring's `mem`/`intCast_mem`/`add_mem'`/`mul_mem'` fields. The decisive call-site evidence (Phase 6.0) is that this *same project* already defines `integerRing : Subring L` (`Coefficients.lean:41`) — the closed unit ball as a subring, in the identical `[NormedField L] [IsUltrametricDist L]` setting, with byte-for-byte the same closure proofs — and uses it across a dozen files. The lemma in `ExtLog.lean` re-derives the adjoin-membership fact ad hoc only because that file does not import `Coefficients.lean`; it has exactly one call site, in its own file. So this is a wrapper that the project's own bundled subring makes redundant: a 1-line `Algebra.adjoin_le` composition, not a new lemma.
