## Phase 1 — Comprehend

### Statement (Phase 1)

```lean
lemma mem_zetaIdealPlus_iff (hp2 : p ≠ 2) {x : PadicMeasure p (GPlus p)} :
    x ∈ zetaIdealPlus p hp2 ↔ ∃ l ∈ augmentationIdeal p (G := GPlus p),
      toQPlus p x = toQPlus p l * padicZetaPlus p hp2 :=
  Iff.rfl
```
with `variable (p : ℕ) [hp : Fact p.Prime]`.

`mem_zetaIdealPlus_iff` is **a theorem stating** the following (read mathematically):

A measure `x ∈ Λ(𝒢⁺)` lies in the ideal `I(𝒢⁺)ζ_p` **iff** there exists an element `l` of
the augmentation ideal `I(𝒢⁺) = ker(deg⁺)` such that, in the total fraction ring
`Q(𝒢⁺) = Frac(Λ(𝒢⁺))`, the image of `x` equals `l · ζ_p⁺`. That is: membership in `I(𝒢⁺)ζ_p`
unfolds to "`x` is, up to the structure map `Λ(𝒢⁺) ↪ Q(𝒢⁺)`, of the form `l·ζ_p⁺` with `l`
in the augmentation ideal."

**Crucially**, the right-hand side is **verbatim** the defining `carrier` of the parent
`def zetaIdealPlus` (`ZetaGalois.lean:331–333`):
```lean
def zetaIdealPlus (hp2 : p ≠ 2) : Ideal (PadicMeasure p (GPlus p)) where
  carrier := {x | ∃ l ∈ augmentationIdeal p (G := GPlus p),
    toQPlus p x = toQPlus p l * padicZetaPlus p hp2}
  add_mem' := …; zero_mem' := …; smul_mem' := …
```
So `x ∈ zetaIdealPlus p hp2` is **definitionally** `x ∈ carrier`, i.e. the RHS predicate;
hence the proof is `Iff.rfl`.
