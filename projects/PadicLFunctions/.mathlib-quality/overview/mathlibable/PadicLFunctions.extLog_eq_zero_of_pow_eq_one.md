### Statement (Phase 1)

`PadicLFunctions.extLog_eq_zero_of_pow_eq_one` is **a theorem** stating the
**roots-of-unity / torsion vanishing law** of the extended p-adic logarithm:

> Let `L` be a complete ultrametric normed field that is a normed `ℚ_[p]`-algebra
> (e.g. `ℚ_[p]`, finite extensions, `ℂ_[p]`). If `x ∈ L` is a root of unity — i.e.
> `x^n = 1` for some `n > 0` — then its extended (Iwasawa-branch) logarithm vanishes:
> `extLog x = 0`.

This is precisely the *easy half* of the literature's kernel characterisation of the
extended Iwasawa logarithm: `log_p` extended to `K^×` (via `log_p(p)=0`) is a group
homomorphism into the **torsion-free** additive group `(K,+)`, so every torsion element
(every root of unity) is killed — `μ_∞ ⊆ ker(log_p)`. The full kernel is `p^ℚ·μ_∞` (the
roots of `log_p` are exactly `p^r·ζ`); this theorem is the `μ_∞`-inclusion, the most
frequently used piece. The proof exhibits the root of unity as its own witness:
`x^n = 1 = p^0·1` with the near-1 factor `y = 1` in the exponential ball, so by
well-definedness `extLog x = n⁻¹ • padicLog 1 = n⁻¹ • 0 = 0`.

Variables / typeclasses involved (Lean side):
- `(p : ℕ) [Fact p.Prime]` — the residue prime; the rational scalar `n⁻¹` is taken in `ℚ_[p]` (and disappears, since it multiplies `0`).
- `{L : Type*} [NormedField L] [NormedAlgebra ℚ_[p] L] [IsUltrametricDist L] [CompleteSpace L]` — a complete ultrametric (nonarchimedean) normed field that is a normed `ℚ_[p]`-algebra. `CharZero` is **not** stated (it is implied by the `ℚ_[p]`-algebra structure).

Hypotheses (Lean side):
- `{x : L}` — the element (implicit).
- `{n : ℕ}` `(hn : 0 < n)` — a positive exponent.
- `(hx : x ^ n = 1)` — `x` is an `n`-th root of unity (a torsion element of `Lˣ`).

Conclusion (math): the extended Iwasawa logarithm of a root of unity is `0` (`μ_∞ ⊆ ker log_p`).
Conclusion (Lean): `extLog p x = 0`.

Underlying definitions / lemmas (read from source):
- `extLog p x` (`ExtLog.lean:286`) — `m⁻¹ • padicLog y` for a `Classical.choice` witness, junk `0` off-domain. **`noncomputable def`, not in mathlib.**
- `ExtLogDomain p x` (`ExtLog.lean:278`) — `∃ m k y, 0<m ∧ x^m = p^k·y ∧ InExpBall p (y−1)`; the natural domain of `extLog`. Not in mathlib.
- `InExpBall p x` (`PadicExp.lean:65`) — `‖x‖^{p−1} < (p:ℝ)⁻¹`, the exp ball (⊊ unit ball). Not in mathlib.
- `padicLog x` (`PadicExp.lean:384`) — `∑' n, (−1)^n·(n+1)⁻¹•(x−1)^{n+1}`, junk-total. Not in mathlib.
- Proof inputs: `extLog_eq_of_witness` (`:335`, every witness computes `extLog`), `inExpBall_one_sub_one` (`:346`, `1` is in the exp ball), `padicLog_one` (`PadicExp.lean:388`, `padicLog 1 = 0`), `smul_zero` (mathlib). The full proof is:
