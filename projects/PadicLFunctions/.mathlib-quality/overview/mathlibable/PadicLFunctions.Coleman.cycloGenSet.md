### Statement (Phase 1)

`PadicLFunctions.Coleman.cycloGenSet` is **a definition** of the following:

For a fixed prime `p` and level `n`, it is the *generating set* of the cyclotomic units of `F_n = ℚ(μ_{p^n})`: the set of units `u` of `ℂ_[p]` whose underlying value is one of
- `ξ_{p^n}` (the fixed primitive `p^n`-th root of unity `zetaSys p n`),
- `−ξ_{p^n}`, or
- `ξ_{p^n}^a − 1` for some `a` with `1 ≤ a ≤ p^n − 1`.

In standard notation this is the set `{ ±ξ_{p^n} } ∪ { ξ_{p^n}^a − 1 : 1 ≤ a ≤ p^n − 1 }`, viewed as a subset of `(ℂ_[p])ˣ`. It is the generating set whose multiplicative closure (intersected with the global units `𝒱_n`) defines the group `𝒟_n` of cyclotomic units (`cycloUnits`, line 182–183).

Variables / typeclasses involved (Lean side):
- `p : ℕ`, `[hp : Fact p.Prime]` — the residue prime.
- `n : ℕ` — the level (the field is `F_n = ℚ(μ_{p^n})`).
- ambient field is hardcoded to `ℂ_[p]` (`Coleman.ℂ_[p]`), the `p`-adic complex numbers.
- `zetaSys p n : ℂ_[p]` — a **fixed, hand-picked** compatible system of primitive `p^n`-th roots of unity (`Coleman/Tower.lean:86`, defined via `(exists_compatible_primitiveRoot p).choose`).

Hypotheses (Lean side): none on the def itself (it is a `Set`-builder).

### Literature summary (Phase 3)

Concept identified as: **the generating set of the cyclotomic (a.k.a. circular) units** of a cyclotomic field. Canonical references: Washington, *Introduction to Cyclotomic Fields* §8.1; Wikipedia "Cyclotomic unit"; Sinnott (circular units); Coates–Sujatha, *Cyclotomic Fields and Zeta Values*.

Sources agree on the standard form: **yes.** The group of cyclotomic units of `K = ℚ(ζ_m)` is the subgroup of `K^×` generated by `−1`, `ζ_m`, and `ζ_m^j − 1` (`j = 1, …, m−1`), intersected with the unit group. RJW's `cycloGenSet` (with `m = p^n`) is exactly this generating set, and `cycloUnits = closure(cycloGenSet) ⊓ globalUnits` is exactly "intersected with the units". Faithful to the literature.

Most general standard form: a generating set `{±ζ} ∪ {ζ^a − 1 : 1 ≤ a ≤ m − 1}` attached to **any** primitive `m`-th root of unity `ζ` in **any** commutative ring (number field, ring of integers, local field). The object is the *generating set / subgroup*; the role of `ζ` is "a primitive `m`-th root of unity" — `IsPrimitiveRoot ζ m` — nothing about the ambient field beyond that.

Generality dimensions where the literature varies:
- **Ambient ring**: `K^×` (the field) vs `(𝓞_K)ˣ` (integers) vs an abstract `CommRing` carrying a primitive root. The literature treats all; the cleanest carrier is "a `CommRing A` with `hζ : IsPrimitiveRoot ζ m`".
- **Level**: general conductor `m` vs prime-power `p^n`. The general definition is conductor-free; the prime-power case is the special case RJW needs. (At prime power the *individual* `ζ^a − 1` are non-units — handled by the `⊓ units` step, identically in both the literature and RJW.)
- **Generators of the subgroup of `K^×` vs the unit-only generators**: literature gives both (`{±ζ, ζ^a−1}` for the ambient `K^×` subgroup; `{±ζ^a, (ζ^a−1)/(ζ−1)}` for the unit group directly at prime-power level). RJW uses the first and intersects — a legitimate standard choice.

Disagreement with the literature: **none** mathematically. The only gap is *generality of the Lean encoding* (see Phase 4): RJW pins the ambient field to `ℂ_[p]`, pins `ζ` to one global `.choose` (`zetaSys p n`), pins the level to `p^n`, and packages the result as a bare `Set` rather than the standard *subgroup*.
