### Statement (Phase 1)

`finite_adjoin_int_quotient` is a theorem stating the following:

Let `L` be a normed field that is a normed `ℚ_[p]`-algebra (ultrametric, complete) and let `z ∈ L` be integral over `ℤ`. Form the `ℤ`-subalgebra `R = ℤ[z] = Algebra.adjoin ℤ {z}` and the ideal `(p) = Ideal.span {(p : R)}` it generates from the prime `p`. Then the residue ring `R ⧸ (p)` is **finite**.

Mathematically: *the quotient of an order `ℤ[z]` (a finitely generated `ℤ`-algebra, here sitting inside a characteristic-zero field) by the ideal generated by a rational prime `p` is a finite ring.* This is the standard "finite residue ring of an order" fact, the engine behind the pigeonhole step `z^i(z^m − 1) ∈ p·ℤ[z]`.

Variables / typeclasses involved (Lean side):
- `p : ℕ`, `[Fact p.Prime]` — the rational prime; gives `p ≠ 0`.
- `L : Type*`, `[NormedField L] [NormedAlgebra ℚ_[p] L] [IsUltrametricDist L] [CompleteSpace L]` — the ambient field. (The proof only uses that `L` is a `Ring`/`CommRing`-ish carrier for `IsIntegral`; the analytic typeclasses `NormedAlgebra ℚ_[p] L`, `IsUltrametricDist L`, `CompleteSpace L` are all `omit`-ed for this theorem.)
- `z : L` — the element being adjoined.

Hypotheses (Lean side):
- `hz : IsIntegral ℤ z` — `z` is a root of a monic integer polynomial; this is what makes `ℤ[z]` a finite `ℤ`-module.

Conclusion (math): `ℤ[z] / (p)` is a finite ring.

Conclusion (Lean): `Finite ((Algebra.adjoin ℤ ({z} : Set L)) ⧸ Ideal.span {(p : Algebra.adjoin ℤ ({z} : Set L))})`.

**Proof body (what it does, 3 mathlib facts glued):**
1. `Module.Finite ℤ R` from `Module.Finite.of_fg hz.fg_adjoin_singleton` (integral ⇒ `ℤ[z]` is a f.g. `ℤ`-module).
2. `Module.Finite ℤ (R ⧸ (p))` from `Module.Finite.quotient ℤ _` (quotient of a finite module is finite).
3. `Module.IsTorsion ℤ (R ⧸ (p))` proved inline (≈10 lines): every class is killed by `(p : ℤ)` because `p·a ∈ (p)`.
4. `Module.finite_of_fg_torsion _ this` — a finitely generated torsion `ℤ`-module is finite (structure theorem for f.g. abelian groups).
