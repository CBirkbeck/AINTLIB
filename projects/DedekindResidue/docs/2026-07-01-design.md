# DedekindResidue — design

**Date:** 2026-07-01
**Branch:** `dev/dedekind-residue` (off `main`), worktree `../aintlib-dedekind`
**Status:** approved design; scaffolding done; blueprint + dev tickets to follow

## 1. Goal

Formalise, completely and `sorry`-free, the effective bound of

> K. Belabas, E. Friedman, *Computing the residue of the Dedekind zeta function*,
> Math. Comp. (2015); arXiv:1305.0035 (30 Apr 2013).

Under the Generalized Riemann Hypothesis the paper proves, for a number field `K` of
degree `n > 1`, an explicit bound on the distance between `log κ_K` and a finite,
computable sum `f_K(X)` over prime-ideal powers of norm `< X`, where

```
κ_K = Res_{s=1} ζ_K(s).
```

**Theorem 1** (main). For `X ≥ 69`, assuming GRH,
```
|log κ_K − f_K(X)|
  ≤ (2.324 log Δ_K)/(√X log(3X))
      · ( (1 + 3.88/log(X/9)) (1 + 2/√(log Δ_K))² + 4.26(n−1)/(√X log Δ_K) ),
```
where `Δ_K = |disc K|` and
```
f_K(X) = 3 (B_K(X) − B_K(X/9)) / (2 √X log(3X)),
B_K(X)  = Σ_{𝔭^m, N𝔭^m < X}  (log N𝔭 / N𝔭^{m/2}) ( √X log X / (N𝔭^{m/2} log N𝔭^m) − 1 ).
```
**Theorem 7** / **Corollary 8** are the sharper variants (valid for `X > 9`; Cor. 8 is the
specialisation to Bach's `σ = 1.5`).

## 2. Motivation — the analytic class number formula

By the analytic class number formula (already in mathlib as
`NumberField.dedekindZeta_residue`, proved to be the residue by
`NumberField.tendsto_sub_one_mul_dedekindZeta_nhdsGT`):
```
κ_K = 2^{r₁} (2π)^{r₂} R_K h_K / (w_K √|d_K|).
```
A **certified** approximation of `κ_K` therefore yields a certified value of `h_K R_K` —
exactly the halting datum of Buchmann's class-group / regulator algorithm. Belabas–Friedman
improve Bach's constant from `8.33` to `2.33`, i.e. an `≈ 12.8×` shorter factor base. The
long-term aim of this project is to feed such a certified `κ_K` into class-number and
regulator computation; **this phase delivers the proven bound only** (see §7).

## 3. Scope decisions (settled with the project owner)

- **Strict bottom-up.** No result is stated with an "explicit formula" or "functional
  equation" hypothesis. Those are proved internally; every top-level statement carries
  **only GRH**. During development the skeleton is fully `sorry`ed and *builds*; the
  `sorry`s are filled bottom-up (substrate → explicit formula → estimates).
- **GRH is the sole assumption**, threaded as an explicit hypothesis argument, **never an
  `axiom`**. End state: zero `sorry`; `#print axioms` = `{propext, Classical.choice,
  Quot.sound}` on every public result.
- **Computation deferred.** Executable `f_K(X)`, interval-certified constants, and ideal
  enumeration are a later phase, out of scope here.

## 6. The GRH hypothesis

Mirroring mathlib's `RiemannHypothesis`, stated against the completed Dedekind zeta (whose
zeros are exactly the nontrivial zeros of `ζ_K`):

```lean
/-- GRH for `ζ_K`: every nontrivial zero lies on the critical line `Re s = 1/2`
    (equivalently, in the paper's notation, every `γ_ρ ∈ ℝ`). -/
def GeneralizedRiemannHypothesis (K : Type*) [Field K] [NumberField K] : Prop :=
  ∀ s : ℂ, completedDedekindZeta K s = 0 → s.re = 1 / 2
```

The paper's Lemmas 3–4 use RH for both `ζ_K` and `ζ_k` with `k = ℚ`; the `k = ℚ` side is
mathlib's existing `RiemannHypothesis` for the Riemann zeta, so it is reused. The exact Lean
form pins down once `completedDedekindZeta` (Tier 1) exists.

## 7. Risks / notes

- **Tier 1 is the mountain.** The meromorphic continuation + functional equation of `ζ_K`
  for a *general* number field (Hecke's theorem via a theta function over the ideal lattice)
  is not in mathlib (only Riemann, Dirichlet-L, and — in AINTLIB — the cyclotomic case).
  It is plausibly larger than the paper's own content and is reusable well beyond it; it is a
  mathlib-upstream candidate once green. It is developed **abelian-case-first internally**
  (reuse mathlib's Dirichlet-L FE, as FltRegularBernoulli did for cyclotomic) on the way to
  the general theta proof — this does **not** narrow the final theorem (still general `K`).
- Residues are expressed the mathlib way, as `Tendsto (fun s ↦ (s−1) · f s) … (𝓝 c)` (no
  residue primitive exists), consistent with `dedekindZeta_residue`.
- Prime-ideal / prime-power sums reuse Chebotarev's `NumberFieldEulerProduct`.
