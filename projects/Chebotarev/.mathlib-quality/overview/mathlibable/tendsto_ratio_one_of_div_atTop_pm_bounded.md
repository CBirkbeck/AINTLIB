### Statement (Phase 1)

`tendsto_ratio_one_of_div_atTop_pm_bounded` is a theorem stating the following:

> Let `l` be a filter on `ℝ` and `f, g : ℝ → ℝ`. If `g → +∞` along `l`, and `f`
> agrees with `g` up to a two-sided additive bounded error (there exist constants
> `C₁, C₂` with `g s − C₂ ≤ f s ≤ g s + C₁` eventually along `l`), then
> `f s / g s → 1` along `l`.

In Landau notation: **if `f = g + O(1)` and `g → +∞`, then `f ~ g`** (asymptotic
equivalence). The additive bounded term washes out under division because the
denominator blows up; no property of the denominator beyond divergence is used.

Variables / typeclasses involved (Lean side):
- `l : Filter ℝ` — an arbitrary filter on the reals (the result is filter-generic: `𝓝[>] 1`, `atTop`, etc. all instantiate it).
- `g f : ℝ → ℝ` — the denominator and numerator; both real-valued on a real domain.

Hypotheses (Lean side):
- `hg : Tendsto g l atTop` — the denominator diverges to `+∞`.
- `h_le : ∃ C, ∀ᶠ s in l, f s ≤ g s + C` — eventual upper bound (`f − g` bounded above).
- `h_lower : ∃ C, ∀ᶠ s in l, g s − C ≤ f s` — eventual lower bound (`f − g` bounded below).

Conclusion (math): `f/g → 1`, i.e. `f ~[l] g`.
Conclusion (Lean): `Tendsto (fun s : ℝ ↦ f s / g s) l (𝓝 1)`.

Proof (as written): destructure the two constants; apply
`tendsto_bdd_div_atTop_nhds_zero` (mathlib, `Topology/Algebra/Order/Field.lean:264`)
with `b := -C₂`, `B := C₁` to get `(f − g)/g → 0`; add the constant `1`; then
`congr'` against `(f s / g s)` using `add_div_eq_mul_add_div` on the eventual set
where `g > 0`. It deliberately does **not** use the `Asymptotics.IsEquivalent`
API — the module docstring's Implementation notes say so explicitly.

Sources agree on the standard form: **yes** — `f ∼ g ⟺ lim f/g = 1`, universally.

The conclusion `Tendsto (f/g) l (𝓝 1)` is, in mathlib's vocabulary, exactly

`Asymptotics.IsEquivalent.log` in `SpecificAsymptotics.lean`. Mathlib would not take
a bespoke `Tendsto (f/g) (𝓝 1)`-from-bounded-difference lemma when the general
`IsEquivalent` route is one short composition away and strictly more reusable — this
is the canonical "use the typed asymptotics API, don't hand-roll the ratio limit"
situation.
