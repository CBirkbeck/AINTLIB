### Statement (Phase 1)

`exists_card_norm_le_norm_residue_eq_sub_mul_rpow_le_uniform` is a theorem stating the following.

Let `K` be a number field, `d = [K:ℚ]`, `c` a positive modulus, and `S ≤ (ℤ/c)ˣ` a subgroup of the
unit group of `ℤ/c`. **Assume the Fourier-decay hypothesis `hF`**: for every *nontrivial* character
`χ : S →* ℂˣ`, the `χ`-twisted average of the norm-residue ideal counts has vanishing density, i.e.
`(∑_{s ∈ S} χ(s)·#{I : N(I) ≤ N, N(I) ≡ s (mod c)}) / N → 0` as `N → ∞`. Then there exist a single
real leading constant `κ` and a single real error constant `C'` such that for **every** residue
`a ∈ S` and **every** `N ≥ 1` simultaneously,

  `| #{I nonzero integral ideal of 𝓞_K : N(I) ≤ N, N(I) ≡ a (mod c)}  −  κ·N |  ≤  C'·N^{1 − 1/d}`.

In words: under the hypothesis that every nontrivial Fourier coefficient of the residue-count
densities over `S` vanishes, the per-residue effective ideal counts share one common leading density
`κ` (the count *equidistributes* over the residues in `S`) with a uniform `O(N^{1−1/d})` error.

### Literature summary (Phase 3)

Concept identified as: **the effective ideal-counting function in a ray class / norm-residue class**
— classically Weber–Landau (`x^{1−1/n}` error), refined to ray classes by **Tatuzawa (1973)** and to
fully explicit constants by **Gun–Ramaré–Sivaraman, JNT 243 (2023)** (the file's cited source). The
specific "one leading constant for every class in the subgroup" content is the **equidistribution of
ideals over the (narrow) ray class group**.

Sources agree on the standard form: **yes**. The clean theorem in the literature is:
`#{I : N(I) ≤ x, I ∈ given ray class mod q} = ρ_q·x + O(x^{1−1/n})`, with the leading constant `ρ_q`
**the same for every class** (it depends only on `q` and `K`, not on the class) — i.e. ideals
equidistribute over the ray class group, with an effective error.

Most general standard form: the count over the **full narrow ray class group mod q** (GRS), of which
"residue of the absolute norm mod `c`" (this file) is a quotient/specialisation: norm-residue mod `c`
is the image of the ray-class data under the norm map. The literature states the result over the ray
class group directly; the norm-residue version is a coarsening.

Generality dimensions where the literature varies:
  - **Class structure:** narrow ray class group mod `q` (most general, GRS/Tatuzawa) ⊇ ideal class
    group (Murty–Van Order) ⊇ norm-residue class mod `c` (this file). This file uses the *coarsest*
    (norm-residue), not the finest available.
  - **Error exponent:** `x^{1−1/n}` (Weber, GRS, this file) vs. Landau's sharper `x^{1−2/(n+1)}`.
    This file uses the classical `x^{1−1/n}`, which is the standard "elementary" exponent.
  - **Constant explicitness:** GRS make the `O`-constant fully explicit in `q` and `K`; this file
    leaves it as an existential `∃ C'`. Standard for a non-explicit formalisation.

Disagreement with the literature: the literature states the result as an **unconditional theorem**
(the equidistribution is *proved*, via Hecke `L`-functions / the fundamental-domain count). **This
declaration instead takes the equidistribution's analytic core as a hypothesis** (`hF`, the vanishing
of nontrivial Fourier coefficients) and only performs the *Fourier-inversion bookkeeping* that turns
"all nontrivial twists vanish" into "the leading constant is constant on `S`". So the decl is not the
literature theorem; it is the **final assembly step** of a proof of (a coarsening of) it.
