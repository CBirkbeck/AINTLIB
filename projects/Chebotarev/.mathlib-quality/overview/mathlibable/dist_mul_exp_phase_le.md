### Statement (Phase 1)

`Chebotarev.dist_mul_exp_phase_le` is a **theorem** stating a per-coordinate
"phase–modulus" distance bound used in the Lipschitz-cover construction. With the
unit-circle phase `u(θ) = exp((2π θ − π) i)`, for real `a, b, θc, θd`:

  dist( a·u(θc) , b·u(θd) )  ≤  ‖a‖ · (2π · dist(θc, θd))  +  dist(a, b),

where `a, b` are coerced `ℝ → ℂ` and the distances on the RHS are the real
(`= ℂ`-real-subtype) distances. It splits via the product/bilinear estimate
`dist(a·u, b·v) ≤ ‖a‖·dist(u,v) + ‖v‖·dist(a,b)`, then uses `‖u(θd)‖ = 1` and the
`2π`-Lipschitz bound on the phase map `θ ↦ u(θ)` to replace `dist(u(θc),u(θd))`
by `2π·dist(θc,θd)`.

Variables / typeclasses involved (Lean side):
- `a b θc θd : ℝ` — moduli (`a,b`) and phase parameters (`θc,θd`); no typeclass
  arguments. Everything is hard-wired to `ℝ`/`ℂ`.

Hypotheses (Lean side): none (it is an unconditional inequality).

Conclusion (math): a triangle-type Lipschitz bound on the distance between two
complex numbers given in "modulus × baked-in affine phase" polar form.

Conclusion (Lean):
`dist ((a:ℂ) * exp((2π θc − π) i)) ((b:ℂ) * exp((2π θd − π) i)) ≤ ‖(a:ℂ)‖ * (2π * dist θc θd) + dist (a:ℂ) (b:ℂ)`.

Proof body (3 steps):
1. `(dist_mul_le_norm_mul_dist _ _ _ _).trans` — the project's own product/bilinear
   distance lemma (`NormLeOneLipschitz.lean:362`).
2. `have hav : ‖ud‖ = 1` via `Complex.norm_exp` + `(… * I).re = 0` + `Real.exp_zero`.
3. `have hphase : dist (u(θc)) ud ≤ 2π·dist θc θd` from
   `lipschitzWith_phase.dist_le_mul` (`NormLeOneLipschitz.lean:380`) + `Real.coe_toNNReal`;
   then `rw [hav, one_mul]; gcongr`.
