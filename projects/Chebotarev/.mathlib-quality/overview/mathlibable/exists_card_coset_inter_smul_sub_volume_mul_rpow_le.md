### Statement (Phase 1)

`exists_card_coset_inter_smul_sub_volume_mul_rpow_le` is a theorem stating the following effective
lattice-point count.

Let `Λ = T(ℤ^ι)` be a full-rank lattice in `ℝ^ι` (`ι` finite, `d = #ι`), where `T` is a linear
automorphism of `ι → ℝ`. Let `D ⊆ ℝ^ι` be a bounded measurable set whose topological frontier is
covered by finitely many `M`-Lipschitz images of the unit cube `[0,1]^{d−1}` (Widmer's
"Lipschitz parametrizable boundary of codimension 1"). Then there is a constant `C` — depending
only on the Lipschitz cover data and `T`, **not** on the translate or the dilation — such that for
**every** coset translate `ξ ∈ ℝ^ι` and **every** real dilation factor `t ≥ 1`:

  `| #((ξ + Λ) ∩ t·D)  −  (vol D / |det T|) · t^d |  ≤  C · t^{d−1}`.

Variables / typeclasses (Lean side):
- `{ι : Type*} [Fintype ι]` — index set; `d = Fintype.card ι` is the ambient dimension.
- `(T : (ι → ℝ) ≃ₗ[ℝ] (ι → ℝ))` — the lattice-defining linear automorphism; `Λ = T '' (ℤ-span of Pi.basisFun)`.
- `(D : Set (ι → ℝ))` — the region being counted/dilated.

Hypotheses (Lean side):
- `(hbdd : Bornology.IsBounded D)` — `D` bounded.
- `(hmeas : MeasurableSet D)` — `D` measurable.
- `(hlip : ∃ m M φ, (∀ j, LipschitzWith M (φ j)) ∧ frontier D ⊆ ⋃ j, φ j '' Set.Icc 0 1)` —
  the Lipschitz frontier cover; this is **verbatim Widmer's `Lip(d, m, M)` class** (Definition 2).

Conclusion (math): `#((ξ+Λ) ∩ tD) = (vol D/|det T|)·t^d + O(t^{d−1})`, the implied constant
uniform in `ξ` and `t`.

Conclusion (Lean): `∃ C : ℝ, ∀ ξ t, 1 ≤ t → |(Nat.card ↑((ξ +ᵥ T '' Λ₀) ∩ t • D) : ℝ) −
volume.real D / |LinearMap.det T| * t ^ (Fintype.card ι)| ≤ C * t ^ (Fintype.card ι − 1)`.

### Literature summary (Phase 3)

Concept identified as: **counting lattice points of a full lattice in a homogeneously expanding
bounded region with Lipschitz-parametrizable boundary** — Widmer's theorem (geometry of numbers /
analytic number theory). Classical lineage: Davenport → Schmidt (GTM, p. 347) → Gao → Widmer;
the textbook fundamental-domain version is Lang GTM 110 (Ch. V §2 / Ch. VI §3). Modern effective
refinements: Gun–Ramaré–Sivaraman (JNT 243, 2023) and the arXiv:2604.19681 explicit-counting paper.

Sources agree on the standard form: **yes.** Main term `VolS/det Λ` (= `vol D/|det T|` here);
error governed by the Lipschitz cover constants and the lattice's successive minima; for an
expanding region `tD` this is `O(t^{d−1})`, and `d−1` is the standard exponent for a merely-
Lipschitz (not smooth/curved) boundary.

Most general standard form: stated for an **arbitrary full lattice Λ in ℝⁿ** (Widmer parametrises
by successive minima, not by a chosen automorphism `T`), with the constant **uniform over
translates** (successive minima are translation-invariant) and over real dilation.

Generality dimensions where the literature varies:
  - **lattice presentation**: Widmer/GRS use an *abstract* full lattice Λ with covolume `det Λ`;
    the Lean form fixes a presenting automorphism `T` and writes `|det T|` for the covolume.
    The abstract form is strictly more general (and is exactly mathlib's `ZLattice` + `covolume`).
  - **measurability**: Widmer *derives* "S is measurable" from the Lipschitz-boundary hypothesis
    (Thm 2.2). So a separate measurability assumption is **redundant** at the literature standard.
  - **error exponent**: `d−1` for Lipschitz boundary (this theorem); smaller exponents need
    smoothness/curvature (not relevant here).

Disagreement with the literature: none. The Lean statement is a faithful, correctly-uniform
rendering of Widmer Theorem 2.2 specialised to an expanding region and a `T`-presented lattice.

automorphism `T` (writing `|det T|` for the covolume) in the coordinate space `ι → ℝ`, whereas the
literature standard — and, more decisively, mathlib's own established idiom for exactly this corner
of the library — is an **abstract `ZLattice` `L` with `ZLattice.covolume L`** in a general
finite-dimensional real space. Mathlib's `Tendsto` family is precisely organised this way
(`tendsto_card_div_pow` for the `Pi` case, `'` for inner-product, `''` for general `E`, all via
`Basis.ofZLatticeBasis`/`covolume_eq_det`); the effective version should slot into that same table.
Shipping the `T`-form would create a parallel, coordinate-bound API that composes with none of the
`ZLattice` stack (Minkowski, `covolume_comap`, the number-field `Ideal.Asymptotics` file this
project already imports). The generalisation is MODERATE cost — the mathematics is identical; the
work is the basis-transport boilerplate mathlib already has a template for — and the redundant
`hmeas` hypothesis (Widmer Thm 2.2: "Then S is measurable") should be dropped in the same pass.
Per the Bourbaki-2.0 rule, cost does not downgrade the verdict; the right form is the
`ZLattice`/`covolume` one.

**Reason for the generalisation:**
  - **LITERATURE-WEAKENING**: Phase 4b found the user's form strictly narrower — the standard
    statement is for an abstract full lattice (covolume), not a presenting automorphism `T`, and
    the measurability hypothesis is derivable from Lipschitz boundary.
  - **MODERN-IDIOM (Bourbaki 2.0)**: Phase 4c found the contemporary mathlib formulation
    (`Submodule ℤ E` + `[IsZLattice ℝ L]` + `ZLattice.covolume`, general `E`) — a real
    organisational improvement that makes the result the effective row of mathlib's existing
    `ZLattice.covolume.tendsto_card_div_pow{,',''}` table.
